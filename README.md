# Better-Pomodoro
It is a monochrome split-flap focus timer that behaves like a precision desk instrument rather than a productivity app. Its centerpiece is a genuine mechanical flip-clock — each digit is its own card that falls and lands with weighted easing — set against a quiet charcoal room of drifting dust and lamplight.
    
-The cycle — configurable rounds (1–15) of focus + short break, closed by a long break; the card stock itself inverts to pale grey during rest, the only signal that the state has changed
-Quiet controls — a dimmed play/pause/reset row that only wakes under your cursor, spacebar to run, keyboard-first throughout
-Ambience — a live three-channel noise mixer (rain, drone, wind) synthesized in-browser, no audio files
-Discipline tools — a line-drawn plant that grows with your focus block and wilts if you abandon it, a local seven-day focus log with streaks, screen wake lock, and a Picture-in-Picture clock that floats above whatever you're working on
-Yours to keep — installs as an offline PWA, everything stored on-device, nothing sent anywhere

One instrument, one job: hold your attention for the next twenty-five minutes.
